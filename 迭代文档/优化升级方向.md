## 架构预备

### 跨视频搜索 → 全局索引

当前 ChromaDB 每个视频一个 collection。全局搜索需要：
```
新增 global 索引：所有视频段落 → 统一 collection
  → search(global, q, k=10)
  → 结果带 source_video 字段标识来源
  → 历史 collection 保持不变（单视频问答仍可用）
```

### 多轮对话 → 对话状态管理

```
session = {task_id, history: [{role, content}], ...}
  → 每次 ask() 带最近 N 轮对话上下文
  → 对指代词（"那"、"这个"）做 query expansion
```

### 中文 Embedding → 替换 ChromaDB 嵌入函数

```
当前: SentenceTransformerEmbeddingFunction("all-MiniLM-L6-v2")
替换: SentenceTransformerEmbeddingFunction("shibing624/text2vec-base-chinese")
  或: HuggingFaceEmbeddingFunction("BAAI/bge-m3")
```
